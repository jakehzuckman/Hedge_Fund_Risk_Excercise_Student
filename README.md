# Hedge_Fund_Risk_Excercise_Student
A selection of examples that explore a simplified view of risk factor modeling for non-transparent funds

https://colab.research.google.com/github/jakehzuckman/Hedge_Fund_Risk_Excercise_Student/blob/main/lecture_hf_risk_modeling_NoSolution.ipynb

This .ipynb file contains several exercises aimed at familiarizing students with some simple concepts within Hedge Fund risk factor modeling space. Students will analyze four hypothetical monthly hedge fund return time series against five hypothetical monthly factor return time series with the goal of isolating the primary drivers of return volatility in the subject funds.

# How to begin

1) Open the .ipynb file in Colab
2) In Colab, choose File -> Save a copy in Drive
3) We will walk through the notebook together

The exercise should take roughly 20 minutes. No local installations or separate data downloads should be required.
